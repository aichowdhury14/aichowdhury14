### 🧠 AI engineering

| Project | What it shows | Stack |
|---|---|---|
| **[LLM Eval Pipeline](https://github.com/aichowdhury14/llm-eval-pipeline)** | Scores a RAG bot on a fixed question set, catches regressions between runs | `LLM eval` `RAG` `DuckDB` `Ollama` |
| **[Bangla Mini-GPT](https://github.com/aichowdhury14/bangla-mini-gpt)** | A Bangla LLM from scratch (2.9M–49M params): own tokenizer, Llama-style transformer, GGUF → Ollama | `PyTorch` `transformers` `SentencePiece` |
| **[SLM Lab · TaxBot](https://github.com/aichowdhury14/slm-lab)** | Offline tax assistant on a 1.7B model: schema extraction, code-computed tax, bge-m3 retrieval | `SLM` `RAG` `structured output` `CPU-only` |

| **[Fake Medicine Identifier](https://github.com/aichowdhury14/fake-medicine-identifier)** | Photo → vision-LLM OCR → match against the national medicine directory | `Gemini vision` `OCR` |
